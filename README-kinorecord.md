# 🎧 KinoRecord

Vista pública de solo lectura de mi [discoteca digital](https://kinoluiggi.github.io/discoteca/) —
mismo catálogo, mismo reproductor, sin modo de edición.

**➜ [kinoluiggi.github.io/kinorecord](https://kinoluiggi.github.io/kinorecord/)**

---

## Qué es esto

Este repo aloja un espejo de solo lectura de mi discoteca principal. No tiene
datos propios: en cada carga, lee en vivo el catálogo del repo principal
(`kinoluiggi/discoteca`), así que siempre refleja el estado más reciente sin
que haga falta sincronizar nada a mano.

La diferencia con el sitio principal es simple: aquí el modo curador
(edición de fichas, altas y bajas de álbumes, corrección de fuentes de
audio) está desactivado por completo — es una vista para compartir y
escuchar, no para editar.

## Cómo está hecho

Un único `index.html`, sin build ni dependencias — HTML, CSS y JavaScript
vanilla. Ver el README del [repo principal](https://github.com/kinoluiggi/discoteca)
para el detalle técnico completo (pestañas, APIs usadas, arquitectura).
